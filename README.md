# x-o-console-game
<h2>Консольная игра "Крестики-нолики", разработанная в качестве дипломного проекта курса "PRO Go. Основы программирования" на Stepik.</h2>
## 📋 О проекте
<p>Проект демонстрирует:<br>
- Базовые принципы программирования на Go<br>
- Работу с массивами и циклами<br>
- Организацию кода через функции<br>
- Обработку пользовательского ввода<br>
- Валидацию данных</p>

## 🛠 Технологии
<p>- Go 1.19+<br>
- Стандартная библиотека Go (fmt)</p>

<h1>🎮 Как играть</h1>
<p>
  1. Игроки по очереди вводят цифры от 1 до 9<br>
  2. Каждая цифра соответствует ячейке поля.
</p>
